# Ingeniería Aeroespacial — Ojo de inteligencia 🔍

Enfoque corto:
Diseño, verificación y operación de aeronaves, vehículos espaciales y sistemas asociados.

Ojo de inteligencia:
- Datos: telemetría de vuelo, sensores estructurales, datos CFD, telemetría orbital.
- Tareas IA: surrogate models para CFD, diagnóstico de salud estructural, optimización de trayectorias y control robusto.
- Quick wins: modelo surrogate que acelera iteraciones de diseño y pipeline de HIL (hardware-in-the-loop) para tests.

Competencias clave:
Aerodinámica, estructuras, propulsión, dinámica orbital y verificación.

Herramientas y recursos:
OpenFOAM, GMAT, MATLAB/Simulink, frameworks de testing HIL, Python para análisis de datos.

Ejemplos de proyecto:
1) Predicción de fatiga en componentes críticos a partir de telemetría y acelerómetros.
2) Optimización de perfil de ascenso/despegue para ahorro de combustible con constraints.

Métricas:
Seguridad (incidentes), consumo de combustible, cumplimiento de requisitos de misión.

Quick-start pipeline:
1. Centralizar telemetría y resultados de simulación.
2. Entrenar modelos surrogate y validar con HIL/experimentos.
3. Integrar recomendaciones en ciclos de diseño y revisión técnica.
