# Ingeniería Mecánica — Ojo de inteligencia 🔍

Enfoque corto:
Diseño y manufactura de máquinas, análisis térmico y estructural, sistemas mecánicos.

Ojo de inteligencia:
- Datos: CAD/STEP, resultados FEA, datos de sensores de máquina, inspección visual.
- Tareas IA: optimización topológica asistida, gemelos digitales para mantenimiento predictivo, visión para control calidad.
- Quick wins: pipeline de detección de defecto en piezas mecanizadas con visión industrial y reglas automáticas de rechazo.

Competencias clave:
CAD, FEA, dinámica, manufactura (CNC), metrología.

Herramientas y recursos:
SolidWorks, ANSYS, OpenFOAM, TensorFlow, ROS.

Ejemplos de proyecto:
1) Pipeline de detección de defecto en la línea de mecanizado (visión + microscope imaging).
2) Optimización paramétrica para reducción de masa manteniendo rigidez (simulación + optimización bayesiana).

Métricas:
Tiempo de ciclo, tasa de defectos, eficiencia energética.

Quick-start pipeline:
1. Captura imágenes en línea y medidas dimensionales (sensor/escáner).
2. Entrenar modelo de clasificación (transfer learning) y calibrar umbrales con datos reales.
3. Integración con PLC/MES para acciones automáticas (rechazo, retrabajo).

Recursos:
- Repositorios de modelos TinyML para visión industrial.
- Guías de medición y trazabilidad en procesos CNC.
