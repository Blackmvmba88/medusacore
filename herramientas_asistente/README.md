# Herramientas Asistente

Este repositorio contiene una colección de scripts y herramientas que hemos construido juntos para automatizar y mejorar nuestro flujo de trabajo.

## Scripts

### `limpiar_apps.sh`

Este script cierra un conjunto predefinido de aplicaciones para liberar recursos del sistema.

**Uso:**

```sh
bash limpiar_apps.sh
```

Puedes modificar la lista de aplicaciones a cerrar editando el script directamente.
